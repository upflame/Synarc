# Analysis Patterns Reference

See `skills/synarc-core/SKILL.md` Section S9 for analysis pattern details.

## Code Review Pattern

1. Layer-by-layer analysis (data, business logic, API, UI)
2. Change classification per layer
3. Risk assessment per change
4. Breaking change identification
5. Test gap analysis
6. Security review

## Diff Analysis Pattern

1. Structural changes (imports, exports, types)
2. Behavioral changes (logic, flow, state)
3. Data changes (schema, models, storage)
4. Config changes (env, flags, secrets)
5. Dependency changes (packages, versions)
