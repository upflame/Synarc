# Negative Prompts Reference

See `skills/negative-prompts/SKILL.md` for the complete 30-domain prohibition system.

## Zero-Tolerance Domains

1. Fabrication - never invent files, APIs, or capabilities
2. Risk suppression - never lower risk assessments
3. Scope absorption - never expand scope silently
4. Code quality - never skip validation or error handling
5. Testing - never skip tests on FIX worktypes
6. Architecture - never introduce circular dependencies
7. Security - never bypass auth or skip encryption
8. Data handling - never log PII or expose secrets
9. Error handling - never swallow exceptions silently
10. Hallucination - never claim capabilities you don't have

... and 20 more domains. See `skills/negative-prompts/SKILL.md`.
