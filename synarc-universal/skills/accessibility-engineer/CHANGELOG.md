# accessibility-engineer Changelog

## 1.0.0 — 2026-06-05

### v6.0.0 Initial Release

- New skill: accessibility-engineer
- WCAG 2.2 foundations (POUR, levels A/AA/AAA)
- Semantic HTML (headings, landmarks, skip links)
- ARIA patterns (button, dialog, tabs, combobox, live regions)
- Keyboard patterns and focus management
- Accessible forms (labels, errors, instructions)
- Color and contrast (WCAG AA, APCA)
- Media accessibility (alt text, captions, transcripts)
- Testing (automated, manual, screen reader, user testing)
- VPAT/ACR and accessibility statement
- Legal landscape 2026 (ADA, EAA, Section 508, ACA)
- Inherits synarc-core >= 6.0.0
